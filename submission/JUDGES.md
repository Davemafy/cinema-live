# Judge instructions

Open the production URL recorded in WORKLOG.md. Use **Upload video** or
**Use sample performance** if camera access is unavailable. The sample is a
licensed human dance performance, not a model-generated output.

Enable camera explicitly to preview and record a short take. Camera recording
automatically stops at five seconds. Your original can be previewed and downloaded;
the normalized MP4 is also downloadable. Refresh to recover the current take.

The current build shows **AI rendering unavailable** until the provider and
authorized compute are configured. Do not interpret source playback as an AI
result. No genuine output has been verified yet.

Once real rendering is available, select Silver screen, enter the supplied render
access code if required and transform. The provider queue reports queued/rendering
states. On completion, use Play both from start to compare the normalized source
against the generated video, then Download film. Generation details show the model,
configuration, seed and provider inference time when available. Use New performance
to repeat. A failed job leaves the source available for another explicit attempt.

Browser checks used an emulated camera, not physical hardware. Current captures,
sample upload, preprocessing, source playback/download and recovery are functional;
output quality, generated playback/export and full end-to-end transformation still
need genuine inference verification.
